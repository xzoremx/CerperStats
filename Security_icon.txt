1. Generar clave publica y privada:

node tools/icon_signer.js gen-key --out-private icon_signing_private.pem --out-public-json js/security/icon_public_key.json

------------------------------------------------------------------------------------------------------------------------------------

2. Firma - Caso: 1 SVG

node tools/icon_signer.js sign --private icon_signing_private.pem --svg assets/icons/[[mi_icono.svg]] --out icon_value_signed.txt

3. Hash - Caso: 1 SVG

node tools/icon_signer.js trust --svg assets/icons/[[mi_icono.svg]] --trusted-json js/security/trusted_icons.json

4. Copiar el contenido de icon_value_signed.txt a la BD

------------------------------------------------------------------------------------------------------------------------------------


2. Firma - Caso: SVG + css + js

node tools/icon_signer.js sign --private icon_signing_private.pem --svg assets/icons/[[mi_icono.svg]] --css assets/icons/[[mi_icono.css]] --js assets/icons/[[mi_icono.js]] --out icon_value_signed.txt

3. Hash - Caso: SVG + css + js

node tools/icon_signer.js trust --svg assets/icons/[[mi_icono.svg]] --trusted-json js/security/trusted_icons.json

4. Copiar el contenido de icon_value_signed.txt a la BD
